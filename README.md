# דוח תיק יומי — מאיר

דוח יומי בעברית על תיק ההשקעות, לפי שיטת מיכו (מחיר מול ממוצע נע 150 ימים).
נשלח במייל בימי חול ומתפרסם ב-GitHub Pages.

**אינדיקטורים בלבד — לא ייעוץ השקעות.**

---

## מה עורכים ואיפה

| רוצה לשנות | ערוך את | לא לערוך |
|---|---|---|
| החזקות (קנייה/מכירה) | `trades.json` | ❌ `shares`/`avg` בקוד |
| ספים: MA150, רמות, התראות, RSI, P/E | `config.py` | ❌ מספרים בתוך הלוגיקה |
| כתובת מייל / מספר WhatsApp | `config.py` | |

### לרשום עסקה

הוסף רשומה ל-`trades` בקובץ [`trades.json`](trades.json):

```json
{"date": "2026-08-10", "ticker": "AMZN", "side": "buy", "qty": 5, "price": 265.30}
```

- `price` הוא **למניה**, במטבע של הנייר (דולר, או שקל ל-`.TA`).
- `side` הוא `buy` או `sell`.
- כמות המניות ומחיר הקנייה הממוצע **נגזרים** מהעסקאות. מכירה מקטינה כמות
  ולא נוגעת בממוצע (רווח ממומש אינו עלות). מכירה מלאה מוציאה את הנייר מהדוח.
- טיקר חדש? הוסף לו שורה ב-`meta` באותו קובץ (שם תצוגה ומטבע).

לבדיקה לפני הרצה:

```bash
python3 portfolio.py
```

## הרצה

```bash
python3 send_report.py
```

מייצר דוח, דוחף ל-GitHub Pages, מוודא שהקישור חי, ואז שולח מייל + WhatsApp.

| דגל | מה זה עושה |
|---|---|
| `--no-email` | לא לשלוח מייל |
| `--no-whatsapp` | לא לשלוח WhatsApp (הגשר רץ רק על המק) |
| `--no-publish` | לא לדחוף ל-git |
| `--whatsapp-only` | קיצור ל-`--no-email --no-publish` |

לבדיקה בלי לשלוח ובלי לדחוף כלום:

```bash
python3 send_report.py --no-email --no-whatsapp --no-publish
```

### מי מריץ מה

- **GitHub Action** (`.github/workflows/daily-report.yml`) — ימי חול 08:00,
  מפרסם ושולח את **המייל**.
- **משימה מתוזמנת מקומית** — שולחת **WhatsApp** בלבד, כי הגשר קיים רק על המק.

החלוקה הזו מונעת מיילים כפולים. אל תחזיר שורת cron שמריצה את הצינור המלא —
שני כותבים מתנגשים על אותו `git push`.

## קבצים

| קובץ | תפקיד |
|---|---|
| `generate_report.py` | משיכת נתונים, סיגנלים, בניית ה-HTML ו-`data.json` |
| `send_report.py` | פרסום, מייל, WhatsApp |
| `config.py` | כל הספים והכתובות |
| `portfolio.py` | גזירת החזקות מ-`trades.json` |
| `trades.json` | יומן העסקאות — **המקור היחיד להחזקות** |
| `history.json` | תמונת מצב יומית, מזינה את "מה השתנה" ואת עקומת הביצועים |
| `backfill_history.py` | שחזור חד-פעמי של היסטוריה מקומיטים ישנים |
| `index.html` | דף הנחיתה (נוצר מחדש בכל ריצה) |
| `Portfolio Terminal.html` + `app.jsx` | טרמינל אינטראקטיבי מעל `data.json` |
| `test_portfolio.py` | בדיקות לגזירת העסקאות |

## בדיקות

```bash
python3 test_portfolio.py
```

## סודות
